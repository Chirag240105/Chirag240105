### ⚙️ Architecture Highlights

```text
🔐 Authentication
   ├── OTP hashing
   ├── Attempt limits
   ├── Expiration enforcement
   └── IP rate limiting

🪪 Token Architecture
   ├── RS256 JWT
   ├── Separate token lifecycles
   └── Rotated SHA-256 refresh keys

🏢 Multi-Tenancy
   ├── Company ownership
   ├── Member authorization
   └── Product workflows

📊 Transaction Safety
   └── Prisma Serializable Isolation

📬 Background Processing
   ├── BullMQ
   ├── Notifications
   ├── Retries
   └── Dead-letter queues

   ├── CORS allowlists
   ├── Zod validation
   └── Global rate limiting
```

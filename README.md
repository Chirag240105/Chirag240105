### ▸ 🌱 AgriSmart — AI-Powered Smart Crop Intelligence Platform

> **An end-to-end intelligent agricultural platform connecting farmers & buyers with AI-driven diagnostics, yield/price forecasting, and instant advisory.**

- 🩺 **Disease Detection**: Classifies plant leaf diseases across **38+ plant classes** using a fine-tuned MobileNetV2 deep learning model.
- 📈 **Price Forecasting**: XGBoost regression engine achieving **R² 0.9975 (~99.75% accuracy)** for market price prediction.
- 💬 **AI Agri Assistant**: Natural language farming advisory powered by **Groq LLaMA 3.3 70B**.
- 🌦️ **Weather Intelligence**: Real-time meteorological data integrated via Open-Meteo API.
- 🔐 **Dual Portals & RBAC**: Role-based access control with secure JWT auth for Farmers and Buyers.

```text
Stack: React 18 · TypeScript · Vite · Tailwind CSS · Node.js · Express · MongoDB · Flask · TensorFlow · XGBoost
```

### ▸ 🖥️ Admin Panel — Secondary Computer Marketplace Backend

> **A production-oriented Node.js/Express backend powering a secondary computer marketplace — covering auth, listings, company ownership, broadcast queues, and subscription quotas.**

- 🔑 **Hardened OTP Auth**: Hashed OTP storage, attempt limits, expiry, and IP rate limiting.
- 🪪 **RS256 JWT Lifecycle**: Explicit issuer/audience separation across User, Registration, and Admin tokens with rotated SHA-256 refresh keys.
- 🏢 **Multi-Tenant Seller Engine**: Company ownership structures, member authorization, and post quotas via Prisma serializable transactions.
- 📬 **Asynchronous Queue Pipeline**: BullMQ background workers handling broadcast delivery, retries, and dead-letter queue processing.
- 🛡️ **Defensive Hardening**: Helmet HTTP headers, CORS allowlist, Zod schema validation, and global rate limiters.

```text
Stack: Node.js (ESM) · Express 4 · PostgreSQL · Prisma 7 · Redis · BullMQ · Zod · Vitest
```
